# Bank System

Многомодульный банковский сервис на Spring Boot. Реализован в рамках курса по Java.

## Описание

Банковская система с поддержкой пользователей, счетов, переводов и конвертации балансов в иностранные валюты. Состоит из двух Spring Boot приложений. Администратор создаёт пользователей и счета, клиенты переводят между собой деньги, пополняют и снимают со счёта, ведут список друзей и смотрят историю операций. Все счета ведутся в рублях, но клиент может посмотреть свой баланс в долларах, евро или фунтах по рандомному курсу.

Под капотом два независимых приложения: основной банк и отдельный сервис курсов валют. Они общаются между собой через брокер сообщений Apache Kafka. Клиенты работают с банком через REST API, документация автоматически собирается в Swagger. Данные пользователей и счетов хранятся в PostgreSQL, доступ к ним разграничен через Spring Security с хешированием паролей.

## Модули

- **app** — основной сервис банка (REST контроллеры, Spring Security, точка входа)
- **services** — бизнес-логика (счета, переводы, пользователи, обмен валют)
- **data-access** — слой работы с БД (JPA сущности, репозитории, мапперы)
- **core** — общие модели и исключения
- **contracts** — DTO для межсервисного взаимодействия через Kafka
- **rates-service** — отдельное приложение-поставщик курсов валют

## Стек

- Java 21
- Spring Boot 
- Spring Security
- Spring Data JPA / Hibernate
- Apache Kafka 3.7
- PostgreSQL

## Межсервисное взаимодействие

Два приложения общаются через Apache Kafka двумя способами:

- **Fire-and-forget** — rates-service публикует курсы валют в топик `rates.broadcast` каждые 5 секунд
- **Request-reply** — bank-service запрашивает курс через `rates.request` и получает ответ из `rates.reply`, если в кэше нет актуального значения
